# Melodia Landing Page

Esta é a landing page do **Melodia**, um serviço de música com qualidade superior, playlists personalizadas e interface moderna. O projeto utiliza **HTML** e **Tailwind CSS** para estilização, além de ícones do **Font Awesome**.

## Recursos

- **Responsivo**: Layout adaptável para dispositivos móveis e desktops.
- **Modo Claro/Escuro**: Alternância de tema com botão no menu.
- **Seções**:
  - Hero (destaque principal)
  - Benefícios
  - Funcionalidades
  - Depoimentos de usuários
  - Formulário de contato/newsletter
  - Rodapé com links e redes sociais

## Tecnologias

- [Tailwind CSS](https://tailwindcss.com/)
- [Font Awesome](https://fontawesome.com/)
- [Google Fonts - Poppins](https://fonts.google.com/specimen/Poppins)

## Como usar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em seu navegador.
3. Para personalizar estilos, edite o arquivo `style.css` ou ajuste as classes Tailwind diretamente no HTML.

## Estrutura

- `index.html`: Página principal.
- `style.css`: Arquivo de estilos customizados (opcional).
- Recursos externos via CDN (Tailwind, Font Awesome, Google Fonts).

## Observações

- O modo escuro é salvo no `localStorage` do navegador.
- Imagens e ícones são ilustrativos.
- O formulário de contato não envia dados (apenas visual).
